# My Discord Bot • Control Center

A premium, modern landing page for your Discord bot.

## What’s inside

- **index.html** — Fully self-contained website (HTML + CSS)
- No build step, no dependencies beyond a browser

## How to open

1. Unzip the folder
2. Open `index.html` in Chrome, Firefox, Safari, Edge, or any mobile browser
3. On Android you can use **MT Manager** to extract and open the file
